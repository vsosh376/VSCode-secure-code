# VS Code Secure Code

VS Code расширение для обнаружения и анонимизации "секретов" в коде перед отправкой в LLM или другие внешние сервисы.

## Работа

Расширение: 
- Сканирует рабочую директорию с помощью TruffleHog
- Анализирует код через LLM
- Заменяет найденные секреты на заглушки, типа secret_i, где i - уникальное значение 
- Может сохранять словарь замен для последующего восстановления
- Восстанавливает исходные значения

## Требования

- VS Code 1.85.0 или новее
- [Go](https://go.dev/dl/) - для запуска исходников TruffleHog
- Node.js 20+
- [Ollama](https://ollama.com/download) с локальной моделью, например gpt-oss:20b

## Установка и запуск

```bash
git clone https://github.com/vsosh376/VSCode-secure-code
cd VSCode-secure-code
```

```bash
mv launch.json .vscode/launch.json
```

```bash
unzip trufflehog-3.92.5.zip
```

```bash
npm install
npm run compile
```

Необходимо открыть проект в VS Code подобной IDE, затем нажать `F5` - откроется новое окно VS Code с загруженным расширением.

Для установки расширения в основную систему:

```bash
npm install -g @vscode/vsce
vsce package
code --install-extension vscode-secure-code-0.1.0.vsix
```

После этого расширение будет установлено в вашем VS Code как обычное. Перезапустите VS Code если панель Anonymizer не появилась сразу.

## Использование

1. Открыть рабочую папку с кодом в VS Code подобной IDE
2. Найти раздел **Anonymizer**
3. Нажать кнопку **Hide** - расширение просканирует файлы и заменит секреты заглушками
4. После работы с кодом нажать **Restore** - секреты вернутся на место
5. Кнопка **Save Dictionary** сохраняет словарь замен в папку проекта - если нужно закрыть IDE и продолжить позже

## Работа сканирования

Расширение использует два метода:

1. **Trufflehog** - запускается локально через `go run` из директории `trufflehog-3.92.5/`, сканирует файловую систему и возвращает найденные секреты в JSON
2. **LLM** - разворачивается Ollama, после чего работаем с ней через REST API. Код отправляется в языковую модель для поиска секретов, которые TruffleHog мог пропустить
